# Diagramas

Guardar aquí los diagramas editables y sus exportaciones:

| Archivo | Contenido | Herramienta | Responsable |
|---|---|---|---|
| `c4-contexto.drawio` | Contexto C4: actores y sistemas | draw.io | Josue |
| `c4-contenedores.drawio` | Contenedores: app, API, servicios, BD | draw.io | Josue |
| `flujo-transferencia.png` | Secuencia de una transferencia con controles | draw.io / mermaid | Josue |
| `perimetro.png` | Superficie expuesta y zonas de confianza | draw.io | Horacio |
| `siem-arquitectura.png` | Recolección, correlación y alertas | draw.io | Arun |

Reglas: exportar PNG ≤ 1 MB, nombrar con `fase<NN>-<tema>`, y referenciar cada imagen desde el documento que la usa. La fuente editable (`.drawio`, `.mmd`) se commitea junto a la exportación.
